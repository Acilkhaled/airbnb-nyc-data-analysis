# Airbnb NYC Data Analysis

## Project Overview
This project explores Airbnb listings in New York City to understand pricing, room types, neighborhood distribution, availability, and review patterns.

## Dataset
The dataset contains 48,895 Airbnb listings with information about listing prices, locations, room types, reviews, and availability.

## Tools Used
- Python
- Pandas
- Data Cleaning and Exploratory Data Analysis
- Microsoft Power BI

## Data Preparation
- Checked for duplicate records and duplicate listing IDs.
- Reviewed missing values and data quality.
- Investigated zero and negative prices.
- Validated minimum nights, review counts, and availability values.

## Analysis
The analysis focuses on:
- Price distribution
- Room type distribution
- Listings by neighborhood
- Availability throughout the year
- Review patterns
- Geographic distribution of listings

## Dashboard
Power BI visuals were created to explore Airbnb listings and compare patterns across locations and room types.

## Key Notes
The project uses the provided Airbnb NYC dataset. Findings and conclusions are based on the actual analysis and dashboard.
